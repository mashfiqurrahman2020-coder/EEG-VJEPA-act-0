# V-JEPA Architecture

The **V-JEPA** (Video Joint Embedding Predictive Architecture) is a self-supervised learning model originally designed for video, which we adapt to learn from EEG data.

## EEG as Video

To use a video architecture, we treat the EEG signal like a video stream. The 1D time-series from the 19 spatial channels are reshaped into 2D "frames" that progress over time. 

![V-JEPA EEG as Video](/home/mashfiq/eeg_vjepa/docs/act0_guide/figs/arch_vjepa_eeg_as_video.png)

This allows the model to process spatial and temporal patterns simultaneously, much like analyzing moving objects in a video.

## Network Blocks

The V-JEPA architecture is composed of a deep stack of Transformer blocks. The input data is broken into smaller patches, which are then passed through these blocks. Each block applies self-attention, allowing the network to integrate information across all channels and time points.

![V-JEPA Blocks](/home/mashfiq/eeg_vjepa/docs/act0_guide/figs/arch_vjepa_blocks.png)

## Masking & The JEPA Paradigm

During pretraining, V-JEPA learns by predicting missing parts of the data. We apply **masking** to hide large chunks of the input "video" from the encoder network.

![V-JEPA Masking](/home/mashfiq/eeg_vjepa/docs/act0_guide/figs/arch_vjepa_masking.png)

### The Actual JEPA Block Diagram

The Joint Embedding Predictive Architecture (JEPA) fundamentally relies on an interaction between an **Encoder** and a **Predictor**:
1. **Context Encoder:** Processes the visible, unmasked portions of the signal to build a context representation.
2. **Target Encoder (EMA):** Processes the hidden, masked portions to generate latent targets. This encoder is an Exponential Moving Average (EMA) of the context encoder.
3. **Predictor:** Takes the context representation and attempts to predict the latent targets generated by the target encoder.

![V-JEPA JEPA Architecture](/home/mashfiq/eeg_vjepa/docs/act0_guide/figs/arch_vjepa_jepa.png)

This forces the network to learn rich, robust features without relying on pixel-level (or in our case, waveform-level) reconstruction.
